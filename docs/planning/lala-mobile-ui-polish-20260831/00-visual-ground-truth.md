# 00. 시각 기준

## 1. 인상

LALA는 `밝고 생기 있는 로컬 탐색 도구`로 보인다. 배경은 차갑고 탁한 회색 대신 거의
흰색인 푸른 표면을 사용하고, 핵심 행동은 선명한 LALA 블루로 통일한다. 카테고리에는
블루·코랄·옐로·틸을 함께 사용해 한 가지 색조만 반복하지 않는다.

## 2. 색상

| 역할 | 값 | 사용 |
| --- | --- | --- |
| Primary | `#0B67D8` | 선택, 링크, 주 CTA, 포커스 |
| Primary pressed | `#0754B5` | 눌림 상태 |
| Primary soft | `#EAF3FF` | 선택 행·아이콘 배경 |
| Ink | `#162033` | 제목·핵심 값 |
| Muted | `#5E6B7E` | 보조 설명 |
| Line | `#DCE5F0` | 중성 경계 |
| Canvas | `#F8FBFF` | 앱 배경 |
| Card | `#FFFFFF` | 카드·입력·시트 |
| Coral | `#F25567` | 명소 |
| Sun | `#F4B740` | 맛집 |
| Sky | `#2F80ED` | 행사 |
| Teal | `#0F9D8B` | 문화 |

색만으로 상태를 전달하지 않는다. 선택에는 테두리, 체크 아이콘, 텍스트 굵기를 함께
사용한다. 출처·신선도는 카테고리색이 아니라 중성 메타 스타일을 사용한다.

## 3. 표면과 반경

- 페이지 배경: `Canvas`; 데이터 카드·입력·시트: `Card`.
- 반복 카드 반경 8dp, 모달 시트 상단 반경 24dp.
- 그림자는 카드마다 두껍게 쓰지 않는다. 검색 결과에만 6dp offset의 낮은 그림자와
  명확한 경계를 함께 둔다.
- 선택된 행의 tonal fill은 `Primary soft`, 테두리는 Primary 1.5dp다.

## 4. 타입

- 화면 제목 30/36, 800.
- 카드 제목 16/20, 800~900.
- 본문 15/22, 500.
- 근거 메타 12 이상, 600~700.
- letter spacing은 0이며 viewport 폭으로 글자 크기를 스케일하지 않는다.
