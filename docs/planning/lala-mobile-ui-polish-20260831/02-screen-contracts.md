# 02. 화면 계약

## S1. 여행 유형

```text
┌─────────────────────────────────────┐
│ LALA                      [◎ KO ▾] │
│ 1 / 3                               │
│ 어떤 여행을                         │
│ 계획 중인가요?                      │
│ 더 알맞은 추천을 위한 설명          │
│                                     │
│ [blue icon] 국내 여행          ( ) │
│ [coral icon] 해외 방문         ( ) │
│                                     │
│ [                 다음             ]│
└─────────────────────────────────────┘
```

- 아이콘은 44dp tonal container 안에 둔다.
- 선택된 행은 Primary soft + Primary 1.5dp + check circle을 함께 사용한다.
- CTA는 52dp, disabled 상태도 글자 대비 4.5:1을 목표로 한다.

## S1 상단 언어 메뉴

```text
                 ┌──────────────────┐
                 │ 한국어       KO │
                 │ English      EN ✓│
                 │ 日本語       JA │
                 │ 简体中文      简 │
                 │ 繁體中文      繁 │
                 └──────────────────┘
```

- 흰색 8dp 메뉴, Primary soft 선택 행, check circle.
- 기본 Material 회색 popup surface를 그대로 노출하지 않는다.

## S2. 검색 결과

```text
┌─────────────────────────────────────┐
│ [⌕ 장소·지역 검색              ≡] │
│ [탐색 지역  기본 지역·수원  변경 >]│
│ [전체][명소][맛집][행사][문화]      │
│                                     │
│ ┌──────┬─────────────────────────┐ │
│ │image │ 장소명                 >│ │
│ │      │ 지금 갈 이유 한 줄      │ │
│ │      │ [맛집] 위치       470m  │ │
│ │      │ ◉ 출처 · 기준 시각      │ │
│ └──────┴─────────────────────────┘ │
└─────────────────────────────────────┘
```

- 검색·지역 행은 흰색, 페이지 배경은 Canvas다.
- 선택 카테고리는 해당 카테고리 색을 사용하되 `전체`는 Primary다.
- 카드 우측 chevron은 지도 상세로 이어지는 행동을 명확히 한다.

## S3. 지역 시트

```text
┌─────────────────────────────────────┐
│          지역 선택 · 229개          │
│ 현재 탐색 지역  기본 지역 · 수원    │
│ [⌕ 시군구 또는 시도 검색           ]│
│ [전체 지역 보기][서울][경기]...     │
│ 빠른 선택                           │
│ [pin] 수원시                  (✓)  │
│ [pin] 종로구                   ( ) │
│                                     │
│ [          이 지역으로 탐색        ]│
└─────────────────────────────────────┘
```

- CTA는 safe area 위에 고정하고 목록만 스크롤한다.
- pending 선택이 없으면 CTA는 비활성이다.
- 현재 선택과 pending 선택은 같은 ID일 때만 check를 보인다.
