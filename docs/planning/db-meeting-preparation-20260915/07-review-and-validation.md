## 준비 단계에서 수행한 검증

- 고정 SHA와 canonical SQL 18개 파일의 내용·hash 대조, 누적 CREATE/ALTER 구조 추출.
- 실제 AWS DB catalog SELECT: READ ONLY 확인, 사용자 행 미조회, 메타데이터 응답 checksum 확인.
- 테이블/뷰 존재, 공통 컬럼 타입·NULL, PK/UNIQUE/FK 키, 이름 있는 CHECK 존재·검증 상태, 인덱스 이름 대조.
- 진희님 API 명세·찬혜님 디자인 문구를 브라우저로 다시 읽고 고정 코드와 연결.
- 찬혜님 9/15 작업 보고를 Notion 앱에서 추가 확인. 기기 저장·홈·설정 연결 보고와 고정 main/API 경계를 구분. 해당 작업 SHA·실행 출력은 미인수.
- 현재 GitHub dev 구성·배포 이력, Azure 접근 구독과 대상 불일치, 로컬 접속 실패·기존 Azure DNS 미확인 기록.

문서 링크·Mermaid·JSON·출처·검사 결과를 산출물 검수 기록과 함께 관리한다. 아래 기능 시나리오는 **이번 준비에서 실행하지 않았다**.

산출물 검수: Mermaid 3개 SVG 렌더링, 전체 개요·물리 ERD 시각 확인, 내부 파일 링크·고정 코드 출처 155개 파일/행 링크 확인, 정적 구조/DB 비교 도구 재실행 완료. `pre-commit`의 시크릿 검사에서 Git SHA와 공개 SQL SHA-256 21건을 확인하고 정확한 값만 기존 `.secrets.baseline`에 오탐으로 등록하였다. 검사기·검사 범위는 변경하지 않았다. 원본·문맥 보정 스크립트의 SHA-256도 보존 확인하였다.

변경 파일 대상 `pre-commit` 통과: Ruff 검사·포맷, 시크릿 탐지, 공백·파일 끝·충돌 마커·대형 파일 검사. API·Flutter 기능 테스트는 이 문서 준비의 로컬 검증에 포함하지 않았다.
